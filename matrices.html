Что такое матрица?

Матрица — это прямоугольная таблица чисел, расположенных в строках и столбцах. Формально матрица размера m × n — это функция A: {1..m} × {1..n} → ℝ, где каждому индексу (i, j) сопоставлено число aij.

A = [ a11 a12 … a1n
     a21 a22 … a2n
     ⋮   ⋮  ⋱  ⋮
     am1 am2 … amn ]

Матрицы — универсальный язык для описания линейных преобразований, систем уравнений, графов, квантовых состояний, нейронных сетей и многого другого. Они лежат в основе современной науки и технологий.

Что такое матрица

Матрица — это упорядоченный набор чисел, записанный в виде прямоугольной таблицы. Числа называются элементами матрицы. Матрица размера m×n содержит m строк и n столбцов.

Am×n = [ aij ],   1 ≤ i ≤ m,   1 ≤ j ≤ n

Матрица — это не просто таблица. Это линейный оператор: она действует на векторы, преобразуя их. Умножение матрицы на вектор — это линейное преобразование пространства.

История матриц

От древности до наших дней

Матричные идеи возникли задолго до формального определения. Уже в древнекитайском трактате «Математика в девяти книгах» (≈ II век до н.э.) системы линейных уравнений решались табличным методом, напоминающим метод Гаусса.

  • II в. до н.э. — китайские «фан-чэн» — таблицы коэффициентов СЛАУ.
  • 1545 — Джероламо Кардано публикует правила решения систем.
  • 1683 — Сэки Такакадзу (Япония) применяет определители.
  • 1693 — Лейбниц вводит определители в переписке с Лопиталем.
  • 1750 — Габриэль Крамер формулирует правило Крамера.
  • 1801 — Гаусс разрабатывает метод исключения.
  • 1826 — Коши вводит термин «детерминант».
  • 1850 — Сильвестр вводит термин «matrix» (от лат. «матка»).
  • 1858 — Кэли публикует «A Memoir on the Theory of Matrices».
  • 1870 — Жордан разрабатывает каноническую форму.
  • 1925 — Гейзенберг использует матрицы в квантовой механике.
  • 1930-е — фон Нейман формализует функциональный анализ.
  • 1960-е — Голуб и Кан разрабатывают SVD-алгоритмы.
  • XXI век — матрицы — основа глубокого обучения и GPU-вычислений.

Артур Кэли и рождение алгебры матриц

В 1858 году Артур Кэли опубликовал мемуар, в котором впервые определил матрицу как самостоятельный математический объект и ввёл операции сложения и умножения. Он же заметил, что AB ≠ BA в общем случае — некоммутативность стала фундаментальным свойством матричной алгебры.

Кэли также доказал теорему Гамильтона–Кэли: каждая квадратная матрица удовлетворяет своему характеристическому уравнению.

Что такое определитель

Определитель — число, сопоставляемое квадратной матрице. Обозначается det A или |A|.

det [a b; c d] = ad − bc

Для 3×3 используется правило Саррюса или разложение по строке.

det A = Σj (−1)i+j aij Mij

Определение

Матрица A⁻¹ называется обратной, если:

A · A⁻¹ = A⁻¹ · A = I

Обратная существует тогда и только тогда, когда A квадратная и det A ≠ 0.

Ранг матрицы

Определение

Ранг матрицы — максимальное число линейно независимых строк (или столбцов). Обозначается rank A или r(A). Ранг равен порядку наибольшего ненулевого минора.

0 ≤ rank A ≤ min(m, n)

Интерактив: вычисление ранга

Свойства

  • rank(A) = rank(Aᵀ)
  • rank(AB) ≤ min(rank A, rank B)
  • rank(A + B) ≤ rank A + rank B
  • rank A = n ⇔ det A ≠ 0 (для n×n)
  • Элементарные преобразования не меняют ранг

Теорема о ранге

rank A + dim(ker A) = n   (число столбцов)

Это фундаментальная теорема линейной алгебры, связывающая образ и ядро линейного оператора.

Системы линейных уравнений

Матричная запись

Система линейных алгебраических уравнений (СЛАУ) записывается компактно:

A · x = b

где A — матрица коэффициентов, x — вектор неизвестных, b — вектор правой части.

Интерактив: решатель 2×2 и 3×3

A
b

Теорема Кронекера–Капелли

Система Ax = b совместна тогда и только тогда, когда:

rank A = rank [A | b]
  • Если rank A = rank[A|b] = n — единственное решение.
  • Если rank A = rank[A|b] < n — бесконечно много решений.
  • Если rank A < rank[A|b] — решений нет.

Однородные системы

Если b = 0, система Ax = 0 всегда совместна (x = 0 — тривиальное решение).

Нетривиальные решения существуют, только если det A = 0.

Метод Гаусса

Идея метода

Метод Гаусса (метод последовательного исключения неизвестных) — базовый алгоритм решения СЛАУ.

  1. Составляем расширенную матрицу [A | b].
  2. Прямой ход: приводим к ступенчатому виду элементарными преобразованиями строк.
  3. Обратный ход: выражаем неизвестные снизу вверх.

Пошаговый решатель

Элементарные преобразования

  • Перестановка двух строк.
  • Умножение строки на ненулевое число.
  • Прибавление к строке другой строки, умноженной на число.
Все три преобразования не меняют множество решений системы.

Метод Гаусса–Жордана

Разновидность: приводим к единичной матрице слева, тогда справа получаем решение (или A⁻¹).

Расширенный практикум: Метод Гаусса

Ключевая идея. Элементарные преобразования. Этот ориентир связывает формальное определение с вычислительной процедурой и показывает, какую информацию несёт математическая запись.

Разбор небольшого примера

Метод Гаусса использует перестановку строк, умножение строки на ненулевое число и прибавление к строке кратной другой строки. Начинайте с обозначений и структуры объекта, затем переходите к отдельным числам: это уменьшает вероятность перепутать индексы или порядок операций.

Диагонализация

Определение

Матрица A диагонализируема, если существует обратимая P и диагональная D такие, что:

A = P · D · P⁻¹

Столбцы P — собственные векторы, диагональ D — собственные значения.

Интерактив: диагонализация 2×2

Условия диагонализируемости

  • Матрица n×n диагонализируема ⇔ есть n линейно независимых собственных векторов.
  • Если все λ различны — гарантированно диагонализируема.
  • Симметричные матрицы всегда диагонализируемы (даже ортогонально).

Применение: быстрое возведение в степень

Ak = P · Dk · P⁻¹

Это ключевое тождество для динамических систем, марковских цепей, анализа устойчивости.

Три массива: (row, col, value) для каждого ненулевого элемента.

Аналогично CSR, но по столбцам. Удобно для доступа к столбцам.

function mul(A, B) {
  const n = A.length, m = B[0].length, k = B.length;
  const C = Array.from({length:n}, () => new Array(m).fill(0));
  for (let i=0;i<n;i++)
    for (let j=0;j<m;j++)
      for (let t=0;t<k;t++)
        C[i][j] += A[i][t]*B[t][j];
  return C;
}
